# MathBox 數學工具箱 v4

純 HTML / CSS / JavaScript，可直接部署到 GitHub Pages。

## 功能
- 科學計算機、度數/弧度
- 二次方程式與解題步驟
- 函數繪圖、拖曳、縮放
- 函數分析
- 統計：平均、中位數、眾數、變異數、標準差、四分位數、IQR
- 矩陣：加法、乘法、行列式、反矩陣
- 排列組合：階乘、P、C
- 機率與二項分布
- 幾何：圓、矩形、三角形、梯形、球、圓柱、圓錐、兩點距離
- 等差/等比數列
- 單位換算
- 化學方程式自動配平
- localStorage 計算紀錄
- 深色模式
- 手機版 RWD

## GitHub Pages
將 `index.html`、`style.css`、`script.js`、`README.md` 放在 repository 根目錄，Pages 使用 `main` branch 的 root 即可。
