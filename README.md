# MathBox v8.0

MathBox 是可直接部署到 GitHub Pages 的數學與化學學習工具網站。

## 資料夾分類
- `math/`：數學工具中心
  - `basic/` 基礎計算
  - `algebra/` 數與代數
  - `functions/` 函數與座標
  - `geometry/` 幾何
  - `statistics/` 統計
  - `number/` 數論
  - `sequence/` 數列
- `chemistry/`：化學
  - `basic/` 化學計算
  - `learning/` 化學教學
- `learning/`：高中數學教學與公式

根目錄仍保留舊版工具頁，方便相容原本的連結。
